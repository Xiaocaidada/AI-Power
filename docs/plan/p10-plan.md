# P10 记忆增强规划

## 目标

把现有 Agent 记忆升级为平台级 **Personal Memory Hub**：

> 记忆总览 → 管理 → 自动提取/审核 → 检索注入 → 项目/Agent 联动 → 关系图谱 → 质量优化

不新建第二套记忆系统，扩展 `agent_memories` 并补齐候选、版本、关系、使用记录与设置。

## 已确认决策

- 默认关闭，用户显式开启；开启后默认“确认后保存”。
- 作用域：`global | project | agent` 三层。
- 提取时机：消息完成后异步提取，夜间做 consolidation。
- 图谱第一版：记忆-记忆 + 项目/文档/Agent 外部引用节点。

## 关键边界

- 记忆 ≠ 聊天记录；只保存长期价值信息。
- 记忆 ≠ 知识库；两类上下文分开检索、分开展示引用。
- 默认不自动写入；秘密信息硬拦截。
- 项目记忆默认不跨项目；Agent 不自动获得全部个人记忆。
- 图谱不做通用实体消歧；第一版只做记忆与引用节点。
