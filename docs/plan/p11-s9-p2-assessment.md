# P11-S9：P2 高级能力评估

日期：2026-11-24

## 判定原则

P2 项只有在同时满足以下条件时才在本轮落地：

1. 不依赖真实外部账号、合同、密钥或人工授权。
2. 能复用现有权限、模型注册表、用量账本和错误码。
3. 风险可控，默认关闭或用户显式触发，失败有类型化错误。
4. 不引入新的计费、合规或商业决策。

## 评估结论

| ID | 能力 | 结论 | 原因 |
|---|---|---|---|
| P2-1 | API / 云盘 / 第三方知识数据源 | 后续按需 | 需要 OAuth、第三方凭证、连接器生命周期与网络策略；现有 URL/HTML/站点导入已覆盖手动来源。 |
| P2-2 | 多模态知识处理 | 后续按需 | 图像/表格/音视频深度理解依赖具体视觉/多模态模型能力与按 KB 模型配置；现有 OCR 已覆盖文本抽取。 |
| P2-3 | 知识图谱与实体消歧 | 后续按需 | 需要实体识别、实体存储、别名合并与图谱 schema；当前记忆图谱只支持记忆/项目/Agent/文档节点与关系类型。 |
| P2-4 | LLM 语义矛盾检测 | **本轮实现（按需触发）** | 复用用户 Provider/平台模型与用量账本；只生成待确认建议，不自动修改记忆。 |
| P2-5 | 实时协同画布 | 后续按需 | 需要 CRDT/WebSocket、在线状态与冲突合并；当前画布为单用户自动保存，协同语义需产品决策。 |
| P2-6 | 工作流市场与商业化 | 明确不做 | 涉及支付、结算、版权与发布审核，属于真实商业/合规决策。 |

## P2-4 实现范围

- `POST /memories/quality/semantic`：用户显式触发，可选 `provider_id`/`model`，默认最多 12 对。
- 仅在记忆中心启用时可用；模型优先级为请求参数 → `MEMORY_EXTRACTION_*` → 模型目录首个启用模型。
- 候选对来自同分类、作用域兼容的活跃记忆，按词面/标签相似度排序，控制调用成本。
- LLM 必须返回 `pair_id/contradicts/confidence/reason` JSON；只接受 `confidence >= 0.6` 且 pair 合法的结果。
- 结果为 `kind=resolve_conflict` 的待确认建议（`payload.semantic=true`），沿用现有应用/忽略/回滚流程。
- 相同记忆对已有 pending 建议时不再重复创建。
- 用量写入 `usage_events.source=memory_quality`，并新增 Prometheus 检查/矛盾计数。

## 明确未实现

- 自动应用语义冲突结论。
- 跨分类、跨作用域的矛盾推断。
- 实体级知识图谱与实体消歧。
- 外部数据源连接器、多模态深度理解、实时协同画布、市场计费。
