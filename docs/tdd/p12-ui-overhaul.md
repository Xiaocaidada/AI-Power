# P12 UI 改版（ui改动v1）

日期：2026-11-24
状态：已完成本轮推荐组合

## 范围

按 `ui改动v1.txt` 与推荐组合执行：

- 收敛门户导航，品牌改为 AI Power。
- 首页内联单轮对话、重点能力与 Provider 露出。
- 控制台工作区与导航重构。
- Arena / Prompt Lab / 模型评测独立轻量壳。
- Chat 思考等级移动到发送按钮左侧，网页搜索只保留快捷开关。
- 深度研究、Agent 任务融入对话；Chat 左栏增加工具入口。
- CSS 渐进动画。

## 实现

### 门户

- `PortalLayout`：
  - Logo + 模型广场 + Agent 广场 + 创作下拉 + 资源下拉。
  - 移除首页、公告/帮助顶层、控制台顶层和邮箱展示。
  - 右侧：控制台图标、GitHub、获取 API Key、立即体验、通知、头像。
  - `UserAvatarMenu`：邮箱首字母头像，菜单含控制台、个人资料、API Key、设置、退出。
  - 移动端折叠菜单。
- 品牌：`common.appName` 与 `index.html` 改为 AI Power。
- `VITE_GITHUB_URL` 可覆盖 GitHub 地址，默认 `https://github.com`。

### 首页

- Hero 使用共享 `Composer`，登录后直接在当前页发起单轮对话：
  - 创建会话、SSE 流式输出、停止、错误提示。
  - 回答下方提供“继续多轮对话”进入 `/chat/:id`。
- 未登录发送时保存 prompt 到 `sessionStorage`，登录回首页后恢复。
- 新增“平台重点能力”卡片：Agent Studio、自定义知识库、长期记忆。
- 新增“接入你自己的模型服务”区块与 Provider 数量。
- “进入控制台”快速入口改为 `/dashboard`。

### 控制台

- `AppShell` 工作区块：
  - 工作区首字母、名称、plan、role、切换下拉、成员/项目/归档/搜索。
- 导航分组：
  - 概览：总览
  - 对话：对话、多模态
  - 知识：知识库、文件、长期记忆
  - 构建：Agent、Agent Studio、工作流、协作、评测
  - 扩展：Skills、连接器、插件
  - 账户：用量、设置
  - 管理后台折叠。
- 移除控制台中的 Arena / Prompt Lab / 模型评测 / 深度研究 / Agent 任务入口。
- 总览增加“模型服务”快捷卡。
- ChatSidebar 工作区块同步升级，并新增“工具”区：知识库、记忆、Skills、连接器、插件。

### 独立创作壳

- 新增 `ToolLayout`：AI Power、返回首页、模型广场、控制台、头像。
- `/arena`、`/prompt-lab`、`/model-eval` 移出 `AppShell`，使用独立轻量壳，保留登录要求。

### 对话页

- 思考等级从底部左侧移动到发送按钮左侧（`Composer.footerEnd`）。
- 网页搜索从模式下拉移除，只保留快捷开关；聊天页和新建页一致。
- 深度研究：模式下拉保留深度研究，新增“深度研究”快捷动作，把当前输入作为研究主题创建待确认计划。
- Agent 任务：输入栏新增“Agent 任务”，对话内创建任务、显示计划/状态，可确认、暂停、继续、取消，详情跳 `/tasks?task=`。
- Agent 任务完成后自动刷新会话消息。
- Chat 左栏工具区提供知识库、记忆、Skills、连接器、插件入口。

### 动效

- `animate-page`：页面淡入上移。
- `animate-pop`：弹层/下拉。
- 尊重 `prefers-reduced-motion`。
- 未对 SSE token 更新做动画，避免卡顿。

### 输入区二次调整

- Agent 模式回到模式下拉；选中后 Agent 选择器出现在模式右侧，网页搜索隐藏。
- 新会话输入区只保留模式、按条件显示的 Agent/网页搜索、模型、思考和发送；项目、知识库、Prompt 模板移到对话框下方，避免换行。
- 学习模式选中时，难度、学习方式和目标输入框显示在对话框上方，并与对话框左对齐。
- 网页搜索只在普通/网页搜索模式且模型支持 `chat` 时显示；Agent、深度研究、学习模式以及不兼容模型不显示。
- 独立“深度研究”按钮移除，深度研究通过模式下拉进入；避免未选择时占用输入区。
- 知识库多选在没有任何知识库时显示空状态“还没有知识库”和“新建知识库”入口。
- 新会话删除“高级设置”弹窗：Prompt 模板改为独立选择器，变量就地展开；学习参数、搜索 Provider 按模式就地显示；插件收进 Agent 模式下的插件弹窗。
- 历史会话新增模型切换器；思考等级改为只显示当前值的 popover（`标准 ▾`），不支持等级置灰；`MessageItem` 运行详情不再显示“思考等级”前缀。
- 历史会话不再因 `conversation.agent` 永久锁定模式下拉；退出 Agent 时后端会清 `agent`，有插件/自定义 Agent 时给出明确原因。
- Agent 任务只在 Agent 模式显示，并可在对话内展开步骤、产出物和工具调用统计。
- 首页模型选择器统一为 `PopoverSelect`，文案改为“自动”，移除输入区右侧提示；答消息显示在输入框上方，背景改为页面 `bg-canvas`，不再使用对话框的 `bg-surface`。
- 会话侧栏底部“已归档”移到会话列表标题行图标，避免底部导航拥挤。
- 后端 `PATCH /conversations/{id}` 切换到 Agent 模式时校验当前模型 `tools` 能力，返回 `capability_unsupported`。

- 浏览器实测首页内联对话：输入后由本地 Qwen 流式返回回答，并生成“继续多轮对话”链接。
- 浏览器实测 Chat：思考等级与发送按钮同区、深度研究/Agent 任务按钮、Agent 任务弹窗、左栏工具入口均正常。
- 浏览器实测 `/arena`：使用独立 ToolLayout，无控制台侧栏。
- 二次调整浏览器验证：新会话 Agent 模式选择后，Agent 选择器出现在模式右侧并隐藏网页搜索；学习模式的难度/方式/目标显示在对话框上方且左边缘与对话框一致；知识库无数据时显示空状态和新建入口；普通模式下只保留网页搜索，独立深度研究按钮已移除；历史会话可退出 Agent 模式并恢复网页搜索；模型选择器成功切换并同步顶部标识；运行详情只显示“标准”。首页实测答消息卡片位于输入框上方，背景 class 为 `bg-canvas`。

## 边界

已解决：

- 导航不再换行，低频入口收进下拉/折叠。
- 首页登录状态可直接单轮对话；未登录保留 prompt。
- 控制台工作区视觉层级和导航密度改善。
- 思考等级、网页搜索、深度研究、Agent 任务在对话页收口。
- 独立创作页不再套控制台侧栏。
- 动画不阻塞流式输出。

未实现/后续：

- 首页为“单轮内联 + 继续多轮跳转”，不是完整多轮聊天。
- 头像首版为邮箱首字母，未实现头像图片上传与后端字段。
- GitHub 地址使用环境变量/占位，需配置真实仓库地址。
- 移动端导航为折叠菜单，未做更细的手势/抽屉动效。
- Agent 任务在对话内可展开步骤/产出物；审批操作与跨会话完整时间线仍在 `/tasks` 详情。
- Agent 模式与网页搜索/深度研究仍互斥：后端 Agent 分支优先，真正的 Agent 联网需要把 web search 注册为 Agent 工具（后续切片）。
- 深度研究内部已包含网页检索，不与网页搜索叠加。
- 学习参数、搜索 Provider 改为模式上下文内联；插件使用独立弹窗，不再有统一“高级设置”入口。
- 未新增前端 E2E 用例；本轮使用 typecheck、Vitest、build 与浏览器手动检查。
- 未做全站视觉回归截图基线。
