# P9-S0/S1 Knowledge Studio 地基与处理画布

## 范围

按 `docs/plan/p9-plan.md`：工作流类型化、知识处理画布 MVP、暂存/应用闭环。

## 数据模型

- `workflows.kind`（`agent | knowledge_process | knowledge_retrieval`）。
- `workflow_versions.schema_version`。
- `workflow_runs.input_payload / output_payload / applied_at`。
- `knowledge_bases.process_workflow_version_id / retrieval_workflow_version_id`。
- `documents.process_version_id`。
- `workflow_artifacts(run_id, node_id, kind, payload)`：节点预览产物。
- `knowledge_chunk_drafts`：运行级暂存切片 + 向量，应用后替换线上索引。
- 迁移：`e2f3a4b5c6d7_p9_s0_s1.py`。

## 工作流与节点

- `GET /workflows?kind=` 过滤；`POST /workflows` 接受 `kind`。
- `GET /workflows/catalog?kind=knowledge_process` 返回处理节点目录与三套模板。
- 处理节点：`start`、`parse_document`、`clean_text`、`chunk_text`、
  `embed_chunks`、`index_knowledge`、`output`。
- 校验为单链：唯一 start/output、每个中间节点一进一出、无分支/条件/环。
- 处理调度：`POST /workflows/{id}/runs` 需 `document_id`；worker 根据
  `workflow.kind` 分发到 `KnowledgeProcessRunner`。

## 执行

- `parse_document`：复用现有解析器，限制页数；校验文件位于 `UPLOAD_DIR`。
- `clean_text`：空白压缩、URL/控制字符清理。
- `chunk_text`：固定、Markdown（标题上下文）、递归；支持 chunk size/overlap/
  min chars/标题保留。
- `embed_chunks`：使用 KB 的 Embedding 配置与批次；校验维度。
- `index_knowledge`：写入 `knowledge_chunk_drafts`，不触碰线上 chunks。
- 每节点写 `workflow_node_runs` 与 `workflow_artifacts`；SSE 复用
  `workflow_start/node_start/node_end/workflow_end`。
- 取消在节点边界检查。

## 应用

- `GET /knowledge-bases/{id}/processing/binding`
- `PUT /knowledge-bases/{id}/processing/binding`
- `GET /knowledge-bases/{id}/processing/runs`
- `GET /knowledge-bases/{id}/processing/runs/{run_id}/preview`
- `POST /knowledge-bases/{id}/processing/runs/{run_id}/apply`
- 应用要求 run 完成、暂存切片全部有向量；事务内替换文档 chunks/embeddings，
  更新 `documents.status=ready`、`process_version_id` 与 run `applied_at`。

## 边界

- 处理流程为单链，不支持分支/条件/循环。
- 上传自动执行绑定流程尚未接入；当前通过 Studio 试运行后应用。
- 解析仍为 PDF/MD/TXT/CSV/DOCX；OCR/PPT/Excel 后置。
- 预览产物截断（文本/页/切片），完整切片保留在暂存表。
- 处理运行暂不写 LLM/usage 账本（embedding 未计费）。
