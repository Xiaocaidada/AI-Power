# P10-S0/S1 记忆中心基础与管理

## S0 数据模型

扩展 `agent_memories`：

- `project_id`、`scope_type`（global/project/agent）、`category`
- `status`（candidate/active/conflict/expired/archived/rejected）
- `source_type/source_id/source_ref`、`confidence`、`sensitivity`
- `enabled/pinned/favorite/tags/valid_until/use_count/content_hash/version`
- `memory_metadata`

新增表：

- `memory_candidates`：提取候选、建议动作、目标记忆、来源、状态。
- `memory_versions`：不可变版本快照、编辑人、变更原因。
- `memory_relations`：多态 from/to（memory/project/document/agent）+ 关系类型/依据。
- `memory_usage_events`：记忆、上下文、模型、相关性、注入字符（只追加）。
- `memory_settings`：默认关闭、自动提取、需确认、自动保存、分类白名单、
  项目/Agent 提取、跨模型、注入上限、禁止主题、保留天数。

迁移 `d7e8f9a0b1c2`：

- 旧记忆回填 `scope_type=global`、`category=kind`、`source_type=source`、
  `status=active`。
- 新建唯一约束与索引。

## S1 API 与页面

服务 `app/services/memories.py`：

- 统一筛选：q、category、status、scope_type、project_id、agent_id、tag、
  favorite、pinned、offset/limit。
- 创建/更新：校验作用域、项目/Agent 归属、分类、秘密信息；
  创建写 v1 版本，更新写新版本并重算 content_hash/embedding。
- 统计：总量/生效/待确认/冲突/过期/归档、分类与作用域分布、最近/高频。
- 版本：列表 + 恢复（恢复也生成新版本）。
- 关系：列表/创建/删除。
- 批量：状态、分类、作用域、项目/Agent、启用、标签。
- 设置：读取时懒创建默认值；默认 `enabled=false`、`require_confirmation=true`。
- `memory_context` 新增状态/启用/有效期过滤，支持 `project_id`；
  global + 当前 Agent/项目记忆。

API `/memories`：

- `GET` 列表（筛选）、`POST` 创建、`GET /stats`、`GET/PATCH /settings`、
  `GET /usage`、`POST /batch`
- `GET/PATCH/DELETE /{id}`、`GET /{id}/versions`、
  `POST /{id}/versions/{version}/restore`
- `GET/POST /{id}/relations`、`DELETE /{id}/relations/{relation_id}`

前端：

- `/memory` 重写为 Memory Hub：总览、全部记忆、待确认、使用记录、规则设置。
- 总览：状态卡片、分类分布、高频使用、最近更新。
- 全部：搜索 + 分类/状态/作用域/项目/Agent/收藏筛选；卡片操作
  置顶/收藏/编辑/删除/详情。
- 详情：内容、来源、标签、关系、历史版本与恢复。
- 新建/编辑：分类、作用域（项目/Agent 选择）、重要度、敏感级、标签、
  有效期、置顶/收藏/启用。
- 设置：默认关闭提示、自动提取/确认/自动保存、分类白名单、注入限制、
  禁止主题、保留天数。

## 边界

- 项目记忆目前仍按创建者个人可见；项目成员共享读取在 S4 权限矩阵实现。
- 候选表与提取管线已建表，但自动提取/审核在 S2。

- 关系图谱 UI 在 S5；S1 仅提供关系 API 与详情列表。
- 记忆默认关闭：未开启时不提取、不注入。
