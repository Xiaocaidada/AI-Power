# P7 特色功能实施证据

## 范围

按 `docs/plan/p7-plan.md` 实施：

- P7-S0：通用用量来源与多模型流式执行器
- P7-S1：Model Arena
- P7-S2：Prompt Lab
- P7-S3/S4：模型评测中心（数据集、批量执行、规则/人工/AI 评分、指标）

## 共享基础

- `usage_events.source_ref_id`（唯一、可空），来源新增 `arena`、`prompt_lab`、`model_eval`。
- `app/services/model_stream.py`：统一 Provider 流式调用、TTFT、token/成本与账本写入；各业务路由负责持久化自己的响应行。
- 图片/非流式行为保持现有能力边界：新工作台以文本请求为主。

## Model Arena

- 表：`arena_rounds`、`arena_responses`。
- API：创建/列表/详情/删除、单回答 SSE、单回答重试、投票、揭示。
- 盲测未揭示前 API 不返回真实 provider/model；仅返回 A/B/C/D。
- 前端 `/arena`、`/arena/:id`：模型多选、公共参数、2–4 列独立流式、单路停止/重试、停止全部、投票与揭示、历史。

## Prompt Lab

- `prompt_templates.scope`（workspace/platform），平台模板 `workspace_id=NULL`；`prompt_versions` 增加 `user_prompt`、`variable_definitions`、`parameters`。
- `prompt_experiments` / `prompt_experiment_outputs` 快照 System/User Prompt、变量、参数与模型。
- API：模板版本扩展、预览、实验创建/列表/详情/删除/评价、单输出 SSE。
- 前端 `/prompt-lab`：模板库、编辑与新版本、版本选择、变量填写、预览、1–4 模型测试、历史与效果评价。
- 平台初始模板：`scripts/seed_platform_prompts.py`（8 个，已写入真实库）。

## 模型评测中心

- 表：`model_eval_datasets/questions/runs/items/scores`，与现有检索评测分离。
- API：数据集创建/列表/详情/删除/导出、题目追加；任务创建/列表/详情/取消、单条重试、人工评分。
- Arq：`run_model_eval_job`；默认并发 3（1–5），逐条失败隔离，任务取消在条目边界生效。
- 规则评分：关键字/正则；AI 评审：可配置评审模型，返回分数与理由；三种评分分开统计。
- 指标：成功率、规则通过率、AI/人工均分、平均 TTFT/延迟、token 与估算成本。
- 前端 `/model-eval`：数据集 JSON 导入/导出、模型多选、并发/评分方式、运行历史轮询、任务指标、逐题回答、人工评分、失败重试。

## 边界补齐（P7-B）

- Arena：`arena_responses.feedback`（`helpful|unhelpful`，可空）落库；新增
  `PUT /arena/rounds/{id}/responses/{id}/feedback`，重试/重新流式时清空；前端每个回答
  提供“有帮助/没帮助”切换，轮次“最满意回答”投票保留。
- Prompt Lab：新增 `GET /prompt-templates/{id}/diff?from_version=&to_version=`，返回
  System/User Prompt 的行级 `equal/insert/delete` 与新旧行号；前端版本对比对话框。
  新增管理员 `GET/POST/PATCH/DELETE /admin/prompt-templates` 与版本 API，写
  `prompt.platform_create|update|version|delete` 审计；`/admin/prompts` 管理页可新建、
  编辑信息、追加版本、删除平台模板。
- 模型评测：新增题目 `PATCH/DELETE /model-eval/questions/{id}`（被评测条目引用时返回
  409 `question_in_use`）与 `DELETE /model-eval/runs/{id}`（运行中返回 409）；UI 暴露
  数据集题目列表、逐题新增/编辑/删除、数据集删除、任务删除。创建任务时把评分规则写入
  `model_eval_items.scoring_snapshot`，后续编辑题目不改变已创建任务的口径。
- Provider：`LLMProvider` 增加 `async complete()`，`OpenAICompatProvider` 以
  `stream=false` 实现；新增 `ModelCompletion` 统一非流式调用、用量账本与错误语义。
  模型评测答案生成与 AI 评审改用 `complete()`；Provider 未实现时回退聚合 `stream_chat`。
- AI 评审：仍与生成结果分表、按 `method=ai` 记分；新增 `ai_scored/ai_unscored/
  rule_scored/manual_scored` 指标，评审失败原因写入 score.reason，UI 逐条展示分数理由，
  评审失败不影响答案条目状态。

## 仍保留的边界

- Arena / Prompt Lab 的交互仍以 SSE 流式为主；`complete()` 仅用于服务端批处理与评审。
- 平台模板的变量定义与参数编辑沿用版本 JSON，管理员 UI 暂不提供独立变量编辑器。
- 被评测条目引用的题目禁止删除，以保留历史 run 的可追溯性。
