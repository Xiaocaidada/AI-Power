# P8 Agent Studio 实施证据

## 范围

按 `docs/plan/p8-plan.md` 实施 P8 v1：

- Agent 应用实体与发布/复制/收藏/公开广场。
- 独立 Agent Studio 页面（配置、画布、AI 构建、运行）。
- 节点 v2（start/output、画布坐标、Agent/KB 绑定）。
- 自然语言生成工作流（服务端校验 + 自动修复）。
- 最小公开 Agent 广场。

## Agent 应用实体

- `custom_agents` 新增：`mode`、`icon`、`welcome_message`、`examples`、
  `usage_instructions`、`generation_settings`、`kb_ids`、`workflow_id`、
  `published/public_slug/published_at/allow_copy/show_structure/published_snapshot`、
  `usage_count/copy_count/favorite_count`、`source_agent_id`。
- 新增 `agent_favorites(agent_id, user_id)` 唯一收藏表。
- 支持自主 / 工作流 / 混合三种模式；工作流模式必须有 `workflow_id`。
- Agent 多知识库通过 `kb_ids` 保存并做工作区归属校验。

## 发布与复制

- `POST /agents/{id}/publish`：生成脱敏 `published_snapshot`，包含名称、介绍、
  指令、示例、工具、所需 KB/插件名称与（可选）工作流结构；不写入凭证或私有 ID。
- `DELETE /agents/{id}/publish`、`POST /agents/{id}/copy`、
  `PUT/DELETE /agents/{id}/favorite`。
- 公开 API：`GET /market/agents`、`GET /market/agents/{slug}`。
- 复制公开 Agent 使用发布快照，不读取作者私有 KB/插件绑定；工作流结构复制后
  KB 与 Agent 引用被清空，由复制者重新绑定。

## 画布与节点 v2

- `NodeType` 新增 `start`、`output`；`WorkflowNode` 支持 `ui: {x,y}`。
- `KbSearchNodeConfig` 支持 `kb_ids`。
- `AgentNodeConfig` 支持 `agent_id`、`kb_ids`、`tools`、`max_steps`，并允许在绑定
  Agent 时省略 provider/model。
- Runner：start 返回工作流输入；output 返回上游/输入；kb_search 使用节点 KB；
  agent 节点加载自定义 Agent 的指令、工具、KB、插件，并以该 Agent 为 root 运行。
- `GET /workflows/catalog` 返回节点类型、配置字段、限制与变量说明，前端表单、
  后端校验与 AI Builder 共用同一份目录。

## AI Builder

- `POST /agent-builder/generate`：输入需求、构建模型、当前 definition 与 Agent。
- 服务端注入节点目录、可用模型/KB/Agent/插件目录和当前画布。
- 模型返回 `summary/definition/missing_resources`；服务端用
  `validate_definition` 校验，失败时把错误回喂模型修复，最多 3 次。
- 缺失资源（模型、KB、Agent）显式返回，不虚构资源、不自动运行或发布。
- 用量来源新增 `agent_builder`，走统一账本与 `source_ref_id`。

### P8-S5a 多轮会话与自动修复

- `agent_builder_sessions` 持久化 `messages`、`draft_definition`、构建模型与
  Agent/workflow 关联；接口：
  - `POST /agent-builder/sessions`
  - `GET /agent-builder/sessions?agent_id=`
  - `GET /agent-builder/sessions/{id}`
  - `POST /agent-builder/sessions/{id}/messages`
  - `POST /agent-builder/sessions/{id}/apply`
- 消息类型：`generate`、`modify`、`explain`、`fix`。
- `modify` 基于当前草稿返回完整 definition，并计算节点/连接级 diff：
  新增/删除节点、修改节点字段、增删连接。
- `explain` 可只返回解释与优化建议；若给出改进版 definition，也走同一校验与 diff。
- `fix` 接受 `run_id`，服务端加载该工作流运行的节点状态/错误摘要作为上下文，
  返回修复后的完整 definition。
- 服务端仍使用 `validate_definition` 校验并自动修复最多 3 次；explain 可无 definition。
- 前端 AI 构建页改为对话式：模式切换（修改/解释/自动修复）、消息历史、
  变更预览、应用前确认、应用到画布后同步 session。
- 迁移：`f60718293041_p8_builder_sessions.py`。

## 前端

- 新独立全屏工作台：`/studio`、`/studio/:id`（`AgentStudioLayout`）。
- 配置页：基础信息、角色提示词、模式、模型、多 KB、工具、插件、可见范围。
- 画布页：React Flow 拖拽/连线、节点面板、节点配置、条件分支 true/false、
  保存为新 workflow version；无 workflow 时创建并绑定。
- AI 构建页：需求输入、生成、摘要/缺口预览、一键应用到画布。
- 运行页：工作流试运行与节点时间线；自主模式提供对话入口。
- 发布对话框：slug、允许复制、公开结构、取消发布。
- 公开广场：`/market/agents`、`/market/agents/:slug`，支持搜索/最新/热门、
  详情、资源需求、结构展示与复制到工作区。

## P8-S5b 广场与运行闭环

- Agent 列表新增 `scope`：`all|mine|created|copied|favorites|published`；
  前端 `/agents` 提供对应标签页，并支持收藏、复制与发布状态。
- 公开广场新增 `featured` 字段、精选筛选与排序；管理员
  `GET /admin/agents`、`POST /admin/agents/{id}/feature` 管理官方精选。
- 新增 `POST /agents/{id}/use` 统计使用量；创建带自定义 Agent 的会话时也会累加。
- 新增 `GET /agents/{id}/runs`：聚合自主 Agent 会话与工作流运行，返回
  类型、状态、输入/输出、模型、耗时、错误与详情链接。
- 新增独立体验页 `/agents/:id/experience`：
  - 自主模式：创建/复用会话，SSE 流式回答，展示工具调用，支持停止与新会话。
  - 工作流模式：调用现有 workflow run + SSE 节点时间线，支持停止与重跑。
  - 侧栏展示统一运行历史。
- `projects.default_custom_agent_id`：项目可绑定默认自定义 Agent；创建会话未显式
  指定 Agent 时自动继承。项目表单新增 Agent 选择。

## P8-S5c 运行能力与评价

### 节点

- 新增节点类型：`review`、`loop`、`http`、`mcp`、`memory_read`、`memory_write`，
  同步进入 `NODE_CATALOG`，画布、配置面板与 AI Builder 自动获得表单与提示。
- `review`：运行中创建 `workflow_reviews`，节点状态 `waiting_review`；轮询等待
  批准/驳回，定期检查取消；支持 30s–24h 超时。批准输出可覆盖为审核意见/输出，
  驳回返回 `review_rejected`，超时返回 `review_timeout`。
- `loop`：`foreach`（按行或 JSON 数组）与 `repeat`（次数）；可选逐次 LLM 调用
  （`{{item}}/{{index}}/{{iteration}}`）、until 条件、最大迭代与分隔符；不是图环。
- `http`：GET/POST + 模板 URL/headers/body；沿用 SSRF 防护（非 dev HTTPS、
  DNS/私网/保留地址校验、`HTTP_NODE_ALLOWED_HOSTS`、无重定向、超时与响应截断）。
- `mcp`：管理员维护 `mcp_servers`，节点按 `server_id + tool + arguments` 调用；
  MCP 客户端实现 streamable HTTP JSON-RPC（initialize、tools/list、tools/call，
  兼容 JSON 与 SSE 响应、会话头、分页与错误映射）。
- `memory_read` / `memory_write`：按 workspace/user 读写 `agent_memories`；
  读取会更新 `last_used_at`。

### 人工审核 API

- `GET /workflows/reviews?status=pending&run_id=`（workspace 隔离）。
- `GET /workflows/reviews/{id}`。
- `POST /workflows/reviews/{id}/respond`：`approved|rejected` + 可选 comment/output；
  仅 pending 可响应，过期/重复返回 409。
- SSE 新增 `review_requested`、`review_resolved` 与循环 `node_iteration` 事件。

### 长期记忆

- `agent_memories`：workspace/user 隔离，可关联 Agent，scope `user|workspace`，
  kind `fact|preference|summary`，importance 1–5，来源 manual/workflow。
- `/memories` 列表/搜索/创建/更新/删除；跨用户 404。
- 自定义 Agent 开启 `memory_enabled` 后，自主对话会按当前问题注入相关记忆
  （`AGENT_MEMORY_INJECT_LIMIT/CHARS`）；Studio 配置页提供开关。

### 评价与举报

- `agent_reviews` 每用户每 Agent 唯一，评分 1–5 + 内容；写入后重算
  `custom_agents.rating_avg/rating_count`。
- `PUT/DELETE /agents/{id}/review`、`GET /agents/{id}/review`；
  公开 `GET /market/agents/{slug}/reviews`，广场卡片/详情展示评分。
- `agent_reports`：`POST /agents/{id}/report`（同一用户同一 Agent 仅一个 open 举报）。
- 管理员 `GET /admin/agent-reports?status=` 与
  `POST /admin/agent-reports/{id}/resolve`（dismiss / unpublish，写审计）。

### 前端

- `ReviewInbox` 出现在 Studio 运行页与 `/workflows`，3 秒轮询待审核任务，
  支持审核意见与批准/驳回。
- `/memory` 长期记忆页（搜索、范围/Agent 筛选、创建/编辑/删除、重要度）。
- `/admin/mcp` MCP 服务器 CRUD、凭证只写不读、工具发现。
- Agent 广场详情：评分、评价列表、我的评价编辑/删除、举报；管理后台新增
  “举报处理”标签页。

## P8-S5d 边界补齐

- `code`：受限 AST 表达式求值（`app/services/sandbox.py`），变量 `input` / `outputs`
  / `json`，安全内置函数与字符串/列表/字典白名单方法；禁止导入、属性遍历、
  推导式、lambda、多语句、超深/超大结果。
- `database`：`database_connections` 由管理员维护（DSN 加密、只读、行数/超时），
  `database` 节点使用模板参数 + `:name` 绑定，单条 SELECT/WITH，只读事务；
  管理端支持 CRUD 与测试连接；`/admin/databases` 页面。
- MCP：新增 `mcp_resource`（uri）与 `mcp_prompt`（name+arguments）节点，
  客户端支持 `resources/list|read`、`prompts/list|get`；管理员工具弹窗展示
  工具、资源与提示词；新增 `/admin/mcp-servers/{id}/resources|prompts`。
- 长期记忆：`agent_memories.embedding` 向量列；写入/更新时生成嵌入
  （`MEMORY_EMBEDDING_ENABLED`，失败回退），召回按余弦阈值排序；
  `MEMORY_EMBEDDING_ENABLED=false` 时保持词法召回。
- 审核恢复：`workflow_runs.checkpoint` + `paused_at`；审核节点创建后保存
  outputs/node_states/edge_state/pending_review；worker 取消或崩溃后运行置为
  `waiting_review`，启动钩子与每分钟 cron 重新入队；resume 复用原审核与
  node_run，不重跑已完成节点。审核接口在等待态立即入队恢复。
- 评价隐藏：`GET /admin/agent-reviews`、`POST /admin/agent-reviews/{id}/visibility`；
  隐藏后公开列表/评分即时排除，管理后台“评价管理”标签页可恢复。

## 边界

- `code` 是受限表达式而非任意代码执行；`database` 仅 PostgreSQL 只读查询；
  循环仍是节点内迭代，不支持任意子图回边。
- 审核节点通过 checkpoint 在 worker 重启/崩溃后恢复；用户取消或超时会把审核
  标记为 cancelled/expired。
- MCP 支持 streamable HTTP + Bearer、tools/resources/prompts；stdio 与 OAuth 未实现。
- 长期记忆默认向量召回并回退词法；自动注入仅对开启开关的自定义 Agent 生效。
- 评价仅针对已发布 Agent；举报支持驳回/下架，管理员可隐藏/恢复单条评价。
- 敏感插件在工作流运行中没有会话确认上下文时仍返回 `plugin_confirmation_required`。
- 公开 Agent 的复制使用发布快照；体验前需要先复制到访问者自己的工作区并绑定资源。
- 发布/复制会清空 HTTP 节点的 URL/headers/body、MCP 节点的 server/arguments 以及
  记忆节点的内容/查询，复制者必须重新配置，避免凭证或私有数据外泄。
