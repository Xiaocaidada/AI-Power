# P8 Agent Studio 实施证据

## 范围

按 `docs/plan/p8-plan.md` 实施 P8 v1：

- Agent 应用实体与发布/复制/收藏/公开广场。
- 独立 Agent Studio 页面（配置、画布、AI 构建、运行）。
- 节点 v2（start/output、画布坐标、Agent/KB 绑定）。
- 自然语言生成工作流（服务端校验 + 自动修复）。
- 最小公开 Agent 广场。

## Agent 应用实体

- `custom_agents` 新增：`mode`、`icon`、`welcome_message`、`examples`、
  `usage_instructions`、`generation_settings`、`kb_ids`、`workflow_id`、
  `published/public_slug/published_at/allow_copy/show_structure/published_snapshot`、
  `usage_count/copy_count/favorite_count`、`source_agent_id`。
- 新增 `agent_favorites(agent_id, user_id)` 唯一收藏表。
- 支持自主 / 工作流 / 混合三种模式；工作流模式必须有 `workflow_id`。
- Agent 多知识库通过 `kb_ids` 保存并做工作区归属校验。

## 发布与复制

- `POST /agents/{id}/publish`：生成脱敏 `published_snapshot`，包含名称、介绍、
  指令、示例、工具、所需 KB/插件名称与（可选）工作流结构；不写入凭证或私有 ID。
- `DELETE /agents/{id}/publish`、`POST /agents/{id}/copy`、
  `PUT/DELETE /agents/{id}/favorite`。
- 公开 API：`GET /market/agents`、`GET /market/agents/{slug}`。
- 复制公开 Agent 使用发布快照，不读取作者私有 KB/插件绑定；工作流结构复制后
  KB 与 Agent 引用被清空，由复制者重新绑定。

## 画布与节点 v2

- `NodeType` 新增 `start`、`output`；`WorkflowNode` 支持 `ui: {x,y}`。
- `KbSearchNodeConfig` 支持 `kb_ids`。
- `AgentNodeConfig` 支持 `agent_id`、`kb_ids`、`tools`、`max_steps`，并允许在绑定
  Agent 时省略 provider/model。
- Runner：start 返回工作流输入；output 返回上游/输入；kb_search 使用节点 KB；
  agent 节点加载自定义 Agent 的指令、工具、KB、插件，并以该 Agent 为 root 运行。
- `GET /workflows/catalog` 返回节点类型、配置字段、限制与变量说明，前端表单、
  后端校验与 AI Builder 共用同一份目录。

## AI Builder

- `POST /agent-builder/generate`：输入需求、构建模型、当前 definition 与 Agent。
- 服务端注入节点目录、可用模型/KB/Agent/插件目录和当前画布。
- 模型返回 `summary/definition/missing_resources`；服务端用
  `validate_definition` 校验，失败时把错误回喂模型修复，最多 3 次。
- 缺失资源（模型、KB、Agent）显式返回，不虚构资源、不自动运行或发布。
- 用量来源新增 `agent_builder`，走统一账本与 `source_ref_id`。

### P8-S5a 多轮会话与自动修复

- `agent_builder_sessions` 持久化 `messages`、`draft_definition`、构建模型与
  Agent/workflow 关联；接口：
  - `POST /agent-builder/sessions`
  - `GET /agent-builder/sessions?agent_id=`
  - `GET /agent-builder/sessions/{id}`
  - `POST /agent-builder/sessions/{id}/messages`
  - `POST /agent-builder/sessions/{id}/apply`
- 消息类型：`generate`、`modify`、`explain`、`fix`。
- `modify` 基于当前草稿返回完整 definition，并计算节点/连接级 diff：
  新增/删除节点、修改节点字段、增删连接。
- `explain` 可只返回解释与优化建议；若给出改进版 definition，也走同一校验与 diff。
- `fix` 接受 `run_id`，服务端加载该工作流运行的节点状态/错误摘要作为上下文，
  返回修复后的完整 definition。
- 服务端仍使用 `validate_definition` 校验并自动修复最多 3 次；explain 可无 definition。
- 前端 AI 构建页改为对话式：模式切换（修改/解释/自动修复）、消息历史、
  变更预览、应用前确认、应用到画布后同步 session。
- 迁移：`f60718293041_p8_builder_sessions.py`。

## 前端

- 新独立全屏工作台：`/studio`、`/studio/:id`（`AgentStudioLayout`）。
- 配置页：基础信息、角色提示词、模式、模型、多 KB、工具、插件、可见范围。
- 画布页：React Flow 拖拽/连线、节点面板、节点配置、条件分支 true/false、
  保存为新 workflow version；无 workflow 时创建并绑定。
- AI 构建页：需求输入、生成、摘要/缺口预览、一键应用到画布。
- 运行页：工作流试运行与节点时间线；自主模式提供对话入口。
- 发布对话框：slug、允许复制、公开结构、取消发布。
- 公开广场：`/market/agents`、`/market/agents/:slug`，支持搜索/最新/热门、
  详情、资源需求、结构展示与复制到工作区。
