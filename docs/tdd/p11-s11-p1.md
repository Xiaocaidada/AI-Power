# P11-S11：P1 体验闭环

日期：2026-11-24

## 范围

- A-P1-5：Agent 级运行分析与优化建议。
- K-P1-3：文档解析原文预览。
- M-P1-5：记忆有用/无用反馈闭环。

## A-P1-5

`GET /agents/{id}/analytics?days=30`（只读）：

- 聚合自定义 Agent 的聊天会话与绑定工作流运行。
- 指标：总运行、完成/失败/取消/进行中、成功率、平均与 P95 耗时、聊天/工作流 tokens、成本。
- 失败码统计。
- 慢节点 Top 5：节点 id/类型、执行次数、失败次数、平均耗时。
- 启发式建议：失败率偏高、P95 偏高、失败节点、单次成本偏高、运行稳定、无数据。
- `/agents/:id/experience` 页新增运行分析区。

边界：聊天运行无逐次耗时，P95 仅基于工作流运行；建议为规则启发式，不是 AI 自动优化。

## K-P1-3

`GET /documents/{id}/parse-preview`：

- 使用现有解析器重新解析原始文件，返回分页文本。
- 最多 20 页、每页 5000 字符、总计 20000 字符，超出标记截断。
- 文件路径限制在 `UPLOAD_DIR`；不支持类型/解析失败返回类型化 422。
- 知识库文档列表新增“解析预览”按钮与对话框。

边界：预览会重新解析（图片可能触发 OCR/视觉模型）；不保存解析结果，不替代 chunk。

## M-P1-5

数据模型（迁移 `a2b3c4d5e6f7`）：

- `memory_feedback`：workspace/user/memory、rating、comment、context、时间。
- 唯一约束 `(memory_id, user_id, context_type, context_id)`，允许同一记忆在不同使用场景分别反馈。

API：

- `GET /memories/{id}/feedback`：本人各场景汇总计数与最近一条反馈。
- `PUT /memories/{id}/feedback`：按场景 upsert。
- `DELETE /memories/{id}/feedback`：清除本人对该记忆的全部反馈。

闭环：

- `select_memories` 排序加入反馈加成：`+0.02/有用`、`-0.03/无用`，限制在 ±0.06。
- 质量分析新增 `review_feedback` 信息型建议（无用多于有用时提示检查/降权/归档）。
- 记忆详情弹窗新增“有用/无用”按钮与计数。

边界：反馈只影响本用户检索排序，不改变重要性字段；不做自动归档；跨用户不可见。
